# Weather Prediction Web App

## Overview

This project is an early-stage weather prediction web application that utilizes PyTorch for machine learning-based forecasting. The goal is to provide accurate, data-driven weather predictions through a user-friendly web interface. While the frontend is currently hosted on GitHub Pages, the backend is under development and will be migrated to AWS for robust performance and scalability.

## Project Status

**Early Development:**  
- Initial prototype with basic functionalities implemented.
- Frontend hosted on GitHub Pages.
- Backend (PyTorch model, FastAPI API) currently in development and tested on local environments.
- Data from https://www.ncdc.noaa.gov/cdo-web/webservices/v2
- Future plans include full integration of the backend on AWS.

## Key Technologies

- **Frontend:** HTML, CSS, JavaScript (or a framework like React/Vue, if applicable)
- **Backend:** Python, PyTorch, FastAPI
- **Deployment:** GitHub Pages for static hosting; planned AWS migration for backend scalability

## Features

- **Weather Prediction Model:** Utilizes machine learning (PyTorch) for forecasting.
- **User Interface:** Simple and interactive frontend designed for displaying predictions.
- **Scalable Architecture:** Built with a plan for eventual AWS integration, ensuring scalability and performance in production.

## Roadmap

- **Phase 1:** Complete the initial development of the backend API and integrate with the frontend.
- **Phase 2:** Optimize the PyTorch model and expand prediction capabilities.
- **Phase 3:** Migrate the backend to AWS and implement continuous integration and delivery (CI/CD) pipelines.
- **Phase 4:** Enhance the frontend design and add more interactive features based on user feedback.
